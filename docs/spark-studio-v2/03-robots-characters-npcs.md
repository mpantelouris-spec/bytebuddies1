DESIGN PRINCIPLE
The robots and characters should make Spark Studio feel like a living universe rather than a collection of coding exercises.
Children should return not just to finish projects, but to see what their favourite robot says, unlock a new pet, complete a quest, or discover a hidden interaction. Every robot, NPC, and creature should contribute to a world that feels inhabited, playful, and full of personality.

The next chapter should tackle the Programming & Block Coding System—how to transform visual coding into something that feels as enjoyable as building with LEGO while remaining powerful enough to create complete games, simulations, and interactive worlds.
