# Football glTF assets

Drop rigged humanoid player meshes here for FIFA-style characters.
If missing, ByteBuddies uses enhanced procedural `buildFootballPlayer()` fallback.

## Bundled files

| File | Source | License |
|------|--------|---------|
| `footballer.glb`, `player_green.glb`, `player_blue.glb` | Three.js `Xbot.glb` (Mixamo sample) | [Three.js examples license](https://github.com/mrdoob/three.js/blob/master/examples/models/gltf/Xbot.glb) |

Team colours are applied via material tint in `FootballPlayerKit.js`.
Replace with Kenney / Quaternius CC0 sports characters when available.

Optional:
- `crowd_card.png` — fan sprite sheet for stadium billboards
