Privacy Policy

Last updated 13 October 2026 · ByteBuddies (bytebuddies.technology)

This page is the public privacy policy for ByteBuddies, including Google Classroom and Google sign-in.

Who we are

ByteBuddies is a computing platform for schools. Contact: bytebuddies.technology@gmail.com.

What we collect

  • Account details you or a teacher provide (name, email, role, class).
  • Work created on the platform (projects, progress, class assignments).
  • Technical logs needed to run the site (browser type, errors).
  • If you press Connect Google Classroom: Google account email and Classroom data you approve (classes you teach, pupil names/emails on those class lists, coursework and grades you ask us to post or read).

How we use it

We use this information only to run ByteBuddies for your school: sign you in, save work, run a class, and — if you connect Classroom — import classes, match pupils, post work and send grades back.

We do not sell personal data. We do not use Google user data for advertising, credit scoring, or unrelated AI/model training.

Who receives Google user data

We disclose Google user data only as needed to provide the Classroom features you choose:

  • ByteBuddies class teachers: when a teacher imports a Google Classroom course, its course details and pupil roster are stored in the linked ByteBuddies class so that teacher can manage the class. The teacher can see pupil work and grades submitted to that class.
  • Google Classroom: when a teacher chooses to publish ByteBuddies work or send grades, ByteBuddies sends the selected assignment or grade to the linked Google course. Google processes that information under the school's Google Workspace terms and Google's own privacy terms.
  • Firebase / Google Cloud: we use Firebase Authentication and Cloud Firestore to operate ByteBuddies accounts and store class records, including imported course and roster details. Google processes this information as our cloud service provider under its service terms.

We do not disclose Google user data to advertisers, data brokers, or unrelated third parties. We do not sell it.

Google user data (Limited Use)

ByteBuddies's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Classroom access is requested only after you click Connect and approve Google's consent screen. The access token stays in your browser's session storage; ByteBuddies does not save that token in its database. The app treats the token as expired after 55 minutes, and Disconnect removes it from the browser session. We use Google data only for the Classroom features described on this page.

How we protect Google user data

  • Connections between your browser, Google APIs, and Firebase use HTTPS encryption in transit.
  • Class records stored in Cloud Firestore are protected by Google's default encryption at rest. Requests to those records are evaluated by Firebase Authentication and the Firestore security rules configured for the project.
  • Google OAuth access tokens are kept in browser session storage, not in the ByteBuddies database. You can disconnect Google Classroom in ByteBuddies or revoke ByteBuddies access from your Google Account.

Children and schools

ByteBuddies is built for classroom use. Pupil accounts are normally created or invited by a teacher or parent. We ask schools not to collect extra personal details about children (home address, photos that are not needed for the lesson, and so on).

Where it is stored

Account and class data is stored in Firebase Cloud Firestore so the site can load your work on your signed-in devices. Google Classroom data we import is stored with the linked ByteBuddies class for the teacher's classroom features.

How long we keep it

We keep account and class records while they are needed to provide the service. A teacher can disconnect Google Classroom at any time; this removes the browser token but does not automatically delete class records already imported into ByteBuddies. To request deletion of an account or imported Classroom data, email us. We will remove it from active records, subject to any retention required for school administration or law.

Your rights

You can ask to see, correct or delete personal data we hold, or to disconnect Google. Email bytebuddies.technology@gmail.com.

Changes

If this policy changes in a way that matters, we will update this page and the date above.
