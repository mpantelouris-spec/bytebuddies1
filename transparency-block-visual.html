PictoBlox "Turn Video On with Transparency" Block Visualization

Block Overview: The "Turn video on with transparency" block is a statement block that appears in PictoBlox AI/ML extensions (Body Detection, Face Detection, Object Detection). The transparency parameter is displayed as a numeric input field allowing users to set values from 0 to 100 (representing 0% to 100% opacity).

Body Detection Block

[Body] Turn on video on stage with % transparency
Color: #8b5cf6 (Purple)
Type: Statement Block (previous/next connections)
Block ID: bb_body_video_on
Tooltip: "Turn on camera for body detection with transparency"
Field Name: TRANSPARENCY
Field Type: Blockly.FieldNumber
Min Value: 0
Max Value: 100
// JavaScript Implementation
Blockly.Blocks['bb_body_video_on'] = {
  init: function() {
    this.appendDummyInput()
        .appendField("[Body] Turn on video on stage with")
        .appendField(new Blockly.FieldNumber(0, 0, 100), "TRANSPARENCY")
        .appendField("%");
    this.setColour('#8b5cf6');
  }
};

Transparency Parameter Field - Visual Details

Input Field Styling:
  • Type: Blockly.FieldNumber
  • Appearance: White rectangular input box with gray border
  • Default Value: 0
  • Range: 0-100 (constrained on input)
  • Input Method: Direct numeric typing or spinner controls (up/down arrows)
  • Size: Compact inline field (~50-60px width)
  • Border: 1px solid gray (#cccccc or similar)
  • Border Radius: 3-4px (slightly rounded corners)
  • Padding: 4-6px internal spacing
  • Font: Monospace font (typically 12px)
Layout Structure:
  • Layout Type: appendDummyInput() - single line horizontal layout
  • Field Sequence:
    1. Label text: "[Category] Turn on video on stage with"
    2. Transparency number input field (0-100)
    3. Suffix text: "%"
  • Alignment: All fields on same horizontal line, left-aligned
  • Spacing: 3-5px margin between label and input, 0-3px margin between input and suffix
User Interaction:
  • Click on the input field to focus and type a value
  • Values are constrained to 0-100 range (values outside range are clamped)
  • Arrow keys or spinner controls allow incremental adjustment (typically ±1)
  • Selected values are stored as the "TRANSPARENCY" field value
  • Used in generated code/execution as a parameter to set camera transparency
Actual Blockly Rendering:
  • In a real Blockly workspace, the field appears as an editable white box within the colored block
  • The entire block has drop-target connection points on top and bottom
  • The transparency field visually "sits inside" the block (not separate)
  • Text is automatically word-wrapped if the label is very long
  • Font size is typically smaller than the block's primary label

Complete Block Definition Structure

// All three blocks follow the same pattern:

appendDummyInput()
  .appendField(LABEL_TEXT)        // "[Category] Turn on video on stage with"
  .appendField(FIELD_NUMBER)    // FieldNumber(0, 0, 100) - min:0, max:100, default:0
  .appendField(SUFFIX_TEXT);    // "%"

setPreviousStatement(true, null);   // Can connect to previous blocks
setNextStatement(true, null);      // Can connect to next blocks
setColour(HEX_COLOR);                // Category-specific color
