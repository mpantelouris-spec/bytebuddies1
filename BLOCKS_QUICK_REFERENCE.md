## Block Types

### Hat Blocks 🎩
Trigger blocks that start script execution
- When ▶ clicked, On key press, On click, On collision, On message, When face detected, etc.

### Stack Blocks 📚
Regular action blocks that perform tasks
- Move, Say, Play sound, Set variable, etc.

### Reporter Blocks 📊
Return values for use in other blocks
- Mouse X, Mouse Y, Timer, Loudness, etc.

### Boolean Blocks ✓
Return true/false for conditions
- Touching edge?, Key pressed?, Hand detected?, etc.

### C-Blocks 🔲
Container blocks for nested scripts
- Repeat, Forever, If/else, While, etc.

### Cap Blocks 🛑
Terminator blocks that end execution
- Stop all, Delete this clone, etc.

## How to Find a Block

### By Category
Use the left sidebar in Game Builder or Workspace to browse by category

### By Function
All blocks related to a function are grouped together:
- Motion → Move, turn, glide, etc.
- Looks → Say, costume, effects, etc.
- AI → Classify, detect, generate, etc.

### By Hardware
- Arduino → Digital/analog I/O
- Micro:Bit → Display, buttons, sensors
- ESP32 → WiFi, HTTP, MQTT

### By Feature
- **Game Development**: Physics, Game, Sprite blocks
- **AI/ML**: Face, Object, Pose, Emotion detection
- **Robotics**: Motor, Servo, Sensor blocks
- **IoT**: Smart Home, Cloud, MQTT blocks
