# Recovering Your Broken Micro:bit

Your device got a corrupted hex file flashed to it. Here's how to recover it.

## What Happened

- The hex file generated by your site was **invalid/corrupted**
- The flashing appeared to progress (showed 93%) but got stuck
- The device now won't connect (no Bluetooth, no USB recognition)

## Root Cause

**There was no hex validation before flashing.** The code has now been fixed to:
1. ✅ Validate hex before flashing
2. ✅ Show clear error messages if validation fails
3. ✅ Provide recovery steps

## Recovery Steps (Choose ONE)

### Option A: USB Hard Reset (Fastest - Works 95% of the time)

**What you need:** USB cable, your computer

**Steps:**
1. Unplug the micro:bit from USB
2. Wait **10 seconds**
3. Plug it back in
4. Look for the **checkmark (✓)** on the LED display
5. If you see ✓, the bootloader restarted and device is fixed ✅

**If that doesn't work, try Option B:**

### Option B: Physical Reset Button

**What you need:** Micro:bit, USB cable, your computer

**Steps:**
1. Keep the device plugged in via USB
2. Locate the **reset button** on the BACK of the device (small black button)
3. Press and **hold for 3 seconds**
4. Release the button
5. Look for **checkmark (✓)** on display

### Option C: Full Recovery (Nuclear Option)

**For V2 devices only - puts device in safe bootloader mode:**

1. **Unplug** the micro:bit
2. **Hold buttons A + B together** (front of device)
3. Keep holding A + B
4. **Plug in the USB cable** while still holding A + B
5. **Release A + B** buttons
6. Wait for LED to show a pattern (bootloader mode)
7. Drag a **fresh MicroPython hex** to the MICROBIT drive

## Getting Fresh Firmware

Once the device is in bootloader/reset mode:

### Official MicroPython (Recommended)
```
Download from: https://microbit.org/download/
Then drag the .hex to the MICROBIT drive
```

### MakeCode Firmware (Alternative)
```
Download from: https://makecode.microbit.org/
Click "Download" and drag to MICROBIT drive
```

**IMPORTANT:** Use official firmware only. Do NOT use your site's hex until we validate it works.

After recovery:

1. Look for **✓ checkmark** on the micro:bit display
2. Check if **MICROBIT drive** appears in Finder/File Explorer
3. Try **WebUSB flashing** with a simple test program

If you see the checkmark and drive appears, **device is fixed** ✅

## If Hex Generation is Still Broken

The hex might be invalid if:
1. ❌ Python code has syntax errors
2. ❌ Blocks generate invalid MicroPython
3. ❌ HexFS library issue (rare)

**Test with a simple program:**
- Just "display.show(Image.YES)" (no blocks)
- If that works, the issue is your block→Python conversion
- If that fails, the issue is HexFS library

## Your Device is Recoverable

**Don't panic!** Micro:bits have built-in bootloader protection. The device cannot be permanently bricked with just a hex flash. Follow the recovery steps above and it will work again.

If none of the recovery steps work:
1. Try with a different USB cable
2. Try a different USB port
3. Try on a different computer
4. Contact BBC micro:bit support if still broken
